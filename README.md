ventajas biblioteca panda 
la biblioteca panda es más estable y probada para la manipulación de datos 
tiene una comunidad más grande 
y una mejor integración con otras bibliotecas del ecosistema python 
desventajas 
el rendimiento 
no es tan eficiente en el manejo de memoria 
y algunas operaciones pueden hacerse de múltiples formas 
lo que puede causar confusión 
ventajas polar 
rendimiento, procesamiento paralelo y mejor manejo de tipos de datos 
desventajas 
es una biblioteca más nueva.
tiene una menor comunidad
y una integración limitada 
conclusion 
si se va a trabajar con datos pequeños utilizas panda 
y si se va a trabajar con datos grande usas polar
